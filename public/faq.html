Aide & Support

Tout ce qu'il faut savoir pour utiliser SportMap Bénin.

Utilisez la barre de recherche sur la page d'accueil, les filtres par discipline ou commune, ou déplacez-vous sur la carte interactive pour voir les centres autour de vous.
Cliquez sur "Voir détails" sur la fiche du centre, puis utilisez le bouton d'appel ou WhatsApp pour les contacter directement.
La carte affiche tous les centres publiés avec des marqueurs. Vous pouvez zoomer, vous déplacer, et cliquer sur un marqueur pour voir les informations du centre. La carte se centre automatiquement sur votre position si vous autorisez la géolocalisation.
Oui ! Vous pouvez ajouter un centre sans vous authentifier. Rendez-vous sur la page Ajouter un centre, remplissez le formulaire, et votre centre sera soumis à validation par l'administrateur avant publication.
Seul l'administrateur de la plateforme peut valider, modifier ou supprimer les centres. Les informations sont vérifiées avant publication pour garantir leur fiabilité.
La validation est généralement effectuée dans les 48 heures suivant la soumission. Vous recevrez une confirmation par email une fois votre centre publié.
Les notes affichées sur les fiches des centres sont basées sur les retours des utilisateurs. Elles sont modérées par l'administrateur pour garantir leur authenticité.
Envoyez-nous un message via la page Contact. Nous vous répondrons dans les plus brefs délais.
